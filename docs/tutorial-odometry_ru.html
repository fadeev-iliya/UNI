Повороты и езда по точкам

Робот постоянно считает, где он находится. В этом уроке вы научитесь этим пользоваться: поворачивать к точному курсу и ездить по координатам.

Как робот знает, где он

По энкодерам колёс робот всё время пересчитывает три числа — они же показаны на экране: X, Y в миллиметрах и Angle в градусах. Это называется одометрией.

  • При включении робот считает, что стоит в точке (0, 0) и смотрит вдоль оси X.
  • Текущие значения возвращают getAbsX(), getAbsY() и getAbsAngle(), а все три сразу — getOdometry().

Шаги

  1. Сравните два поворота

    robot.rotate(50, 90);     // ещё на 90 градусов вправо от того, как робот стоит сейчас
robot.rotateTo(50, 90);   // встать на курс 90 градусов, как бы он ни стоял сейчас

    rotate() поворачивает на угол, отсчитанный от цели предыдущего манёвра, поэтому в серии манёвров ошибки не копятся. rotateTo() поворачивает к курсу одометрии и не зависит от того, что было раньше: годится и после motors(), stop() или толчка.

  2. Проедьте квадрат на абсолютных курсах

    robot.setPosition(0, 0, 0);
for (int i = 0; i < 4; i++) {
  robot.moveDist(50, 300);
  robot.rotateTo(50, (i + 1) * 90);   // курсы 90, 180, 270, 360
}
robot.displayPrint("Angle", robot.getAngle());

    В конце на экране появится накопленный угол. Чем он ближе к 360, тем точнее робот вернулся к исходному направлению.

  3. Привяжите координаты к полю

    robot.setPosition(0, 0, 0);   // x, y в миллиметрах и курс в градусах

    setPosition() сообщает роботу, где он стоит. Можно задать настоящие координаты стартовой клетки — например, robot.setPosition(150, 150, 90).

  4. Задайте маршрут точками

    const float route[][2] = {
  {400, 0},
  {400, 400},
  {0, 400},
  {0, 0},
};

void setup() {
  robot.begin();
  robot.setPosition(0, 0, 0);

  for (int i = 0; i < 4; i++) {
    robot.moveTo(50, route[i][0], route[i][1]);
    delay(300);
  }
  robot.rotateTo(50, 0);   // в конце вернуть исходный курс
}

  5. Следите за позицией с компьютера

    void loop() {
  robot.printOdometry();
  delay(1000);
}

    Откройте Монитор порта на скорости 115200 бод. Раз в секунду там появится строка с тиками энкодеров, координатами и курсом.

Что должно получиться

Попробуйте изменить

  • Задайте точками треугольник или букву «П».
  • Запустите пример PrecisionTurns: он проезжает квадрат сначала на rotate(), потом на rotateTo() и показывает угол после каждого заезда. Сравните два числа.
  • Удлините маршрут до десяти точек и посмотрите, как растёт ошибка возврата.

Если не получается

  • Робот поехал не в ту сторону. Сверьтесь с рисунком осей: +Y — это вправо. Проверьте порядок аргументов: moveTo(мощность, x, y).
  • Робот возвращается не точно на старт. Ошибка одометрии растёт с пробегом и с проскальзыванием колёс. Почему так, объяснено в разделе «Точность и одометрия».
  • После resetAngle() координаты не обнулились. resetDistance() и resetAngle() сбрасывают только счётчики пути и угла. Положение задаёт setPosition().
