Первый заезд: квадрат

Робот проедет квадрат со стороной 30 см и вернётся на старт. По пути вы освоите две главные команды: проехать расстояние и повернуть на угол.

Перед уроком пройдите «Начало работы»: библиотека установлена, пример Start загружается. Понадобится ровный пол примерно метр на метр.

Что получится

Шаги

  1. Создайте робота

    #include <UNI.h>

UniBase robot("UNI");

void setup() {
  robot.begin();
}

void loop() {
}

    Объект robot — это вся платформа: моторы, энкодеры и экран. Имя в кавычках появится на экране. robot.begin() включает всё это; его можно и не вызывать — первая же команда сделает это сама.

  2. Проедьте прямо

    robot.moveDist(50, 300);   // мощность 50, расстояние 300 мм

    Первое число — мощность в процентах от −100 до 100, второе — расстояние в миллиметрах. Команда блокирующая: следующая строка выполнится только тогда, когда робот доедет.

    Мощность — это скорость в процентах от максимальной: 100 — около 0.3 м/с. Робот удерживает эту скорость по энкодерам, поэтому с малой мощностью он просто едет медленно.

  3. Повернитесь

    robot.rotate(50, 90);      // мощность 50, поворот на 90 градусов

    Положительный угол — поворот направо, отрицательный — налево. Робот поворачивает на месте: колёса вращаются в разные стороны.

  4. Повторите четыре раза

    void setup() {
  robot.begin();

  for (int i = 0; i < 4; i++) {
    robot.moveDist(50, 300);
    robot.rotate(50, 90);
  }
}

    Загрузите скетч и поставьте робота на пол.

Это и есть весь скетч: цикл ставится в setup() скетча из первого шага. Квадрат с поворотами проезжает и пример Файл › Примеры › UNI › PrecisionTurns; его текст — на странице «Примеры».

Попробуйте изменить

  • Сделайте сторону 500 мм. Сравните мощность 30 и 80: как меняется точность остановки?
  • Проедьте квадрат против часовой стрелки: robot.rotate(50, -90).
  • Нарисуйте треугольник: три стороны и три поворота на 120°.
  • Добавьте движение назад и по времени: 
    robot.moveDist(-50, 200);  // назад 200 мм
robot.moveTime(40, 1000);  // вперёд одну секунду
    Отрицательная мощность — это задний ход. moveTime() едет заданное время, а не расстояние; робот плавно замедляется так, чтобы остановиться к концу времени.

Если не получается

  • Экран работает, а робот не едет. Проверьте выключатель батареи и её заряд — см. FAQ.
  • Квадрат не замыкается, углы заметно больше или меньше 90°. Проверьте колёса и покрытие — см. FAQ.
  • На скользком полу робота уводит. Одометрия считает по вращению колёс и проскальзывания не видит — см. «Точность и одометрия».
  • Робот упёрся и примерно через секунду перешёл к следующей команде. Библиотека заметила, что колёса остановились, и завершила команду — см. «Движение и команды».
