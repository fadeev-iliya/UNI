Движение без ожидания и остановка перед препятствием

Пока выполняется moveDist(), программа стоит на месте. Команды с окончанием Async запускают движение и сразу возвращают управление: робот едет, а программа в это время читает датчики.

Для второй половины урока нужен ультразвуковой датчик расстояния, подключённый к портам P6 (trig) и P7 (echo).

Блокирующие и асинхронные команды

У каждой команды движения есть асинхронная пара: moveDist() и moveDistAsync(), rotate() и rotateAsync(), moveTo() и moveToAsync(). К ним добавляются три помощника:

  • isMoving() — едет ли робот прямо сейчас;
  • waitMove() — дождаться конца движения;
  • stop() — прервать движение.

Шаги

  1. Показывайте прогресс во время движения

    robot.moveDistAsync(50, 800);
while (robot.isMoving()) {
  robot.displayPrint("Dist", robot.getDistance());
  delay(100);
}
robot.displayClear();

    Робот едет, а цикл десять раз в секунду выводит на экран пройденный путь.

  2. Подстрахуйтесь от застревания

    robot.moveDistAsync(50, 800);
if (!robot.waitMove(5000)) {   // не доехал за 5 секунд?
  robot.stop(HARD);
  robot.displayPrint("STUCK!");
}

    waitMove() с числом ждёт не дольше указанного времени в миллисекундах и возвращает false, если робот так и не доехал.

  3. Запомните: команда всегда одна

    Очереди команд нет. Новая команда движения отменяет текущую.

    robot.moveDistAsync(50, 500);
robot.rotateAsync(50, 90);   // отменит строку выше: робот только повернёт

    Чтобы выполнить обе, поставьте между ними robot.waitMove();.

  4. Прочитайте датчик расстояния

    UniDev module;

int dist = module.ultraSonic(P6, P7);   // миллиметры; 0 означает «эха нет»

    Датчик измеряет от 20 до 4000 мм. Ноль — это не «препятствие вплотную», а отсутствие ответа, поэтому его всегда проверяют отдельно.

  5. Соберите остановку перед препятствием

    #include <UNI.h>

UniBase robot("UNI");
UniDev module;

const int OBSTACLE_MM = 150;   // дистанция остановки
const int TARGET_MM   = 1500;  // сколько всего проехать
const int FINISH_MM   = 5;     // ближе этого к цели — доехали

void setup() {
  robot.begin();
  robot.resetDistance();
}

void loop() {
  // Цель достигнута — стоим. Движение завершается с небольшим остатком
  // до цели, поэтому сравниваем его с запасом, а не с нулём:
  // иначе робот бесконечно «доезжал» бы последний миллиметр
  int remaining = TARGET_MM - (int)robot.getDistance();
  if (remaining <= FINISH_MM) {
    robot.displayPrint("DONE");
    delay(500);
    return;
  }

  int dist = module.ultraSonic(P6, P7);
  bool blocked = (dist > 0 && dist < OBSTACLE_MM);

  if (blocked) {
    if (robot.isMoving()) {
      robot.stop(HARD);
      robot.displayPrint("Obstacle", dist);
    }
  } else {
    if (!robot.isMoving()) {
      // Едем остаток пути асинхронно, продолжая опрашивать датчик
      robot.moveDistAsync(50, remaining);
      robot.displayClear();
    }
  }

  delay(50);
}

    Цикл двадцать раз в секунду читает датчик. Есть препятствие — останавливает робота; путь свободен, а робот стоит — отправляет его проехать остаток.

Что должно получиться

Попробуйте изменить

  • Увеличьте дистанцию остановки до 300 мм.
  • Мигайте светодиодом, пока робот едет: robot.blinkLED(100) включает мигание, robot.blinkLED(0) выключает.
  • Вместо ожидания объезжайте препятствие: поворот на 90°, дуга и возврат на курс.
  • Подсветите остановку световым кольцом: module.pixelsAll(255, 0, 0).

Если не получается

  • Датчик всегда возвращает 0. Проверьте, что trig подключён к P6, а echo — к P7. Пример DistanceSensors печатает показания в Монитор порта — им удобно проверять подключение.
  • Робот не замечает препятствие. Убедитесь, что в условии есть dist > 0 и что препятствие отражает звук: мягкая ткань и наклонные поверхности возвращают эхо плохо.
  • Выполняется только последняя из двух команд. Между асинхронными командами нужен waitMove() — см. «Движение и команды».
  • Эффекты светового кольца останавливают слежение за датчиком. Они блокируют программу на всю свою длительность — см. «Поведение и блокировки».
