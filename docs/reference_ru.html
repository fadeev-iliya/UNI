Справочник UNI.h

Все функции библиотеки на одной странице. Нажмите на функцию — откроется её описание с параметрами и примером.

Библиотека подключается одной строкой и даёт два класса: UniBase управляет самой платформой, UniDev — портами P1–P8 и модулями на них.

#include <UNI.h>

UniBase robot;   // платформа: моторы, движение, одометрия, экран
UniDev module;   // порты P1–P8: датчики, сервоприводы, кольцо, светофор

UniBase

Платформа: моторы, движение, одометрия, экран. В примерах объект называется robot. Константы — на странице Класс UniBase.

Инициализация

  • UniBase(const char* robotName = "UNI Robot", UniBoardVersion board = UNI_BOARD_AUTO)Создаёт объект робота.
  • void begin(const char* robotName = nullptr)Инициализирует все компоненты робота (Моторы, Энкодеры, OLED, Датчики).

Управление моторами

  • void motors(int powerLeft, int powerRight)Устанавливает мощность для обоих моторов напрямую.
  • void motorLeft(int power)Устанавливает мощность только для левого мотора.
  • void motorRight(int power)Устанавливает мощность только для правого мотора.
  • void motorsArc(int power, float angle)Перемещает робота по дуге с заданной интенсивностью поворота.
  • void motorsSync(int powerLeft, int powerRight)Движение с раздельными скоростями и синхронизацией по энкодерам.
  • void motorsSpeed(float leftMMperSec, float rightMMperSec)То же, что motorsSync(), но скорости колёс задаются в мм/с.
  • void holdPosition()Активное удержание текущей позиции: робот сопротивляется сдвигу с помощью ПИД-регулятора.
  • void stop(int stopType = HARD)Останавливает оба мотора.
  • void stopLeft(int stopType = HARD)Останавливает только левый мотор.
  • void stopRight(int stopType = HARD)Останавливает только правый мотор.

Движение (Блокирующее)

  • bool moveDist(int power, int millimeters)Перемещает робота на определенное расстояние, используя PID-контроль энкодеров.
  • bool moveTime(int power, int milliseconds)Включает моторы на определенное время.
  • bool moveArcDist(int power, int angle, int millimeters)Движение по изогнутой траектории на определенное расстояние.
  • bool moveArcTime(int power, int angle, int milliseconds)Движение по изогнутой траектории в течение определенного времени.
  • bool rotate(int power, int angle)Вращает робота на месте на заданный угол.
  • bool rotateTo(int power, float angleDeg)Поворот к абсолютному курсу одометрии кратчайшим путём.
  • bool moveTo(int power, float x, float y)Движение к заданной точке одометрии: автоматически разворачивается на курс к цели, затем едет прямо.
  • bool moveArcRadius(int power, float radiusMM, float angleDeg)Дуга с точной геометрией: задаётся радиус поворота и угол дуги.

Асинхронное движение

  • void moveDistAsync(int power, int millimeters)Асинхронный аналог moveDist().
  • void moveTimeAsync(int power, int milliseconds)Асинхронный аналог moveTime().
  • void moveArcDistAsync(int power, int angle, int millimeters)Асинхронный аналог moveArcDist().
  • void moveArcTimeAsync(int power, int angle, int milliseconds)Асинхронный аналог moveArcTime().
  • void moveArcRadiusAsync(int power, float radiusMM, float angleDeg)Асинхронный аналог moveArcRadius().
  • void rotateAsync(int power, int angle)Асинхронный аналог rotate().
  • void rotateToAsync(int power, float angleDeg)Асинхронный аналог rotateTo().
  • void moveToAsync(int power, float x, float y)Асинхронный аналог moveTo().
  • bool isMoving()Возвращает true, пока активна задача асинхронного движения.
  • bool waitMove(unsigned long timeoutMs = 0)Блокирует выполнение до завершения текущей асинхронной команды движения.

Одометрия

  • OdometryData getOdometry()Возвращает текущую структуру оценки положения и ориентации.
  • float getAbsX()Возвращает абсолютную координату X в миллиметрах.
  • float getAbsY()Возвращает абсолютную координату Y в миллиметрах.
  • float getAbsAngle()Возвращает абсолютный угол курса в градусах.
  • void resetDistance()Сбрасывает накопленный счетчик расстояния в 0.
  • float getDistance()Возвращает расстояние, пройденное с момента последнего сброса, в миллиметрах.
  • void resetAngle()Сбрасывает накопленный счетчик угла в 0.
  • float getAngle()Возвращает угол поворота с момента последнего сброса, в градусах.
  • void setPosition(float x, float y, float angleDeg)Задаёт начальную позу одометрии.
  • long getLeftTicks() / long getRightTicks()Возвращает количество тиков энкодера для соответствующего мотора.
  • void printOdometry()Выводит текущие значения X, Y и Theta в Serial Monitor.

Скорость

  • int speedToPower(float mmPerSec)Переводит скорость в мм/с в значение power для команд движения.
  • int turnRateToPower(float degPerSec)Переводит скорость поворота в градусах в секунду в значение power для rotate() и rotateTo().
  • float getSpeed()Возвращает измеренную скорость центра робота в мм/с.
  • float getTurnRate()Возвращает измеренную скорость поворота в градусах в секунду.

Дисплей

  • void displayPrint(ValueType value)Очищает экран OLED и выводит переданное значение по центру.
  • void displayPrint(const char* name, ValueType value)Выводит название вверху экрана и значение по центру.
  • void displayText(const char* text)Выводит до 8 строк мелким шрифтом, по 21 символу.
  • void displayClear()Возвращает экран OLED в обычное состояние.

Утилиты

  • int getBatteryPower()Возвращает текущий уровень заряда батареи в процентах (0-100).
  • float getBatteryVoltage()Возвращает напряжение батареи в вольтах.
  • void blinkLED(int interval)Задает фоновую задачу мигания встроенным светодиодом.
  • void UniBaseControl()Включает приём команд по UART от внешнего контроллера (Arduino Nano).

UniDev

Порты P1–P8 и модули на них: датчики, кнопки, сервоприводы, световое кольцо, светофор. В примерах объект называется module. Имена портов — на странице Класс UniDev.

Инициализация

  • void begin()Инициализирует экземпляр UniDev, создавая объект NeoPixel и настраивая режимы пинов.

Датчики

  • int ultraSonic(int trig, int echo)Считывает расстояние с ультразвукового датчика (HC-SR04).
  • int lineSensor(int port)Считывает аналоговое значение с датчика линии.
  • int digitalSensor(int port)Считывает цифровое значение с порта.
  • int analogSensor(int port)Считывает общее аналоговое значение с порта.
  • int getPinMode(uint8_t pin)Возвращает текущий настроенный режим GPIO пина.

Входы

  • void waitButton(int port)Блокирующая функция, останавливающая выполнение программы до тех пор, пока кнопка не будет нажата и отпущена.
  • bool getButtonState(int port)Проверяет, нажата ли кнопка в данный момент.

Сервопривод

  • void servo(int port, int angle)Устанавливает угол сервопривода, подключённого к указанному порту.
  • void servoAttach(int port)Подключает сервопривод к порту и резервирует PWM-канал без задания угла.
  • void servoDetach(int port)Отключает сервопривод: PWM-импульсы прекращаются, привод расслабляется и не держит нагрузку.

Световое кольцо (Базовое)

  • void pixel(int index, int r, int g, int b)Устанавливает цвет одного пикселя.
  • void pixelsAll(int r, int g, int b)Устанавливает все светодиоды кольца в указанный RGB цвет.
  • void pixelsClear()Выключает все светодиоды.
  • void pixelsShow()Отправляет текущий буфер на светодиодную ленту.
  • void pixelsBrightness(int brightness)Устанавливает глобальное масштабирование яркости.

Световое кольцо (Эффекты)

  • void pixelsRainbow(int speed, int duration)Отображает вращающуюся радугу.
  • void pixelsRunning(int r, int g, int b, int duration)Эффект бегущего огня: один пиксель пробегает по кругу один раз.
  • void pixelsBreathing(int r, int g, int b, int duration)Плавно меняет яркость светодиодов (эффект дыхания).
  • void pixelsFill(int r, int g, int b, int duration)Постепенно заполняет кольцо цветом, затем постепенно очищает его.
  • void pixelsSparkle(int r, int g, int b, int duration, int count)Случайным образом мигает отдельными пикселями.
  • void pixelsRotating(int r, int g, int b, int duration, int segmentLength, int rotations)Вращает сегмент зажженных светодиодов вокруг кольца несколько раз.
  • void pixelsSpinner(int r, int g, int b, int duration)Анимация спиннера, зажигающая по одному пикселю, пока кольцо не заполнится, затем перезапускается.

Светофор

  • void setTrafficLight(TrafficLightColor color)Устанавливает состояние модуля светофора.
  • void trafficLightSequence()Запускает последовательность светофора: красный, жёлтый, зелёный — по одной секунде на каждый сигнал, затем гасит все.
