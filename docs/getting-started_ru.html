Начало работы

От установки до первого движения: настроить Arduino IDE, загрузить готовый скетч и убедиться, что робот отвечает. Займёт около 15 минут.

Что понадобится

  • Робот UniBase с заряженной батареей.
  • USB-кабель, который передаёт данные (кабель «только для зарядки» не подойдёт).
  • Компьютер с Arduino IDE версии 2.

Установка

  1. Добавьте поддержку ESP32

    В Arduino IDE откройте Инструменты › Плата › Менеджер плат, найдите esp32 и установите пакет esp32 от Espressif Systems.

  2. Установите библиотеку UNI

    Откройте Скетч › Подключить библиотеку › Управлять библиотеками, найдите UNI и нажмите «Установить». На вопрос о зависимостях ответьте «Установить все»: библиотеке нужны Adafruit GFX Library, Adafruit SSD1306 и Adafruit NeoPixel.

  3. Выберите плату и порт

    Подключите робота по USB и включите его. Выберите Инструменты › Плата › esp32 › ESP32 Dev Module, затем порт в Инструменты › Порт.

Установка из ZIP-архива

Если Менеджер библиотек недоступен, скачайте архив со страницы релизов на GitHub и добавьте его через Скетч › Подключить библиотеку › Добавить .ZIP библиотеку. Зависимости при этом не подтягиваются: три библиотеки Adafruit установите через Менеджер библиотек отдельно.

Первый скетч

  1. Откройте пример Start

    Файл › Примеры › UNI › Start. Это минимальная программа: она создаёт робота и включает экран.

    #include <UNI.h>

UniBase robot;
UniDev module;

void setup() {
  robot.begin("UNI");
}

void loop() {
}

  2. Загрузите его в робота

    Нажмите кнопку «Загрузить» и дождитесь сообщения об окончании загрузки. Программа запускается сразу после неё.

  3. Посмотрите на экран

    Через секунду на экране появится состояние робота:

    Имя, нулевые координаты и слово Ready означают, что экран, моторы и энкодеры запущены и библиотека работает.

Первое движение

Программа запускается сразу после загрузки и при каждом включении робота. Прежде чем добавлять движение, поставьте робота на пол или приподнимите колёса, чтобы он не уехал со стола вместе с кабелем.

Добавьте в setup() две команды и загрузите скетч снова:

void setup() {
  robot.begin("UNI");

  robot.moveDist(50, 300);  // вперёд 300 мм на мощности 50
  robot.rotate(50, 90);     // поворот направо на 90 градусов
}

Робот проедет 30 см и повернёт направо. На экране изменятся X и Angle — это одометрия: робот сам считает, где он находится.

Удобнее запускать движение по кнопке. Если к порту P5 подключена кнопка, поставьте перед командами движения строку module.waitButton(P5); — робот будет ждать нажатия.

Если что-то пошло не так

Что видно Что проверить
Порт не появляется в меню Кабель должен передавать данные. Попробуйте другой кабель и другой USB-разъём.
Ошибка Adafruit_SSD1306.h: No such file or directory Не установлены зависимости — три библиотеки Adafruit из шага 2.
Ошибка UNI.h: No such file or directory Библиотека UNI не установлена. Повторите шаг 2 и перезапустите Arduino IDE.
Экран остаётся тёмным Убедитесь, что робот включён. Откройте Монитор порта на скорости 115200 бод: если экран не найден, библиотека сообщит об этом.
Экран работает, а робот не едет Проверьте выключатель батареи и её заряд.

Больше случаев разобрано в разделе FAQ.
