What is UNI?

The UNI library is designed to simplify the development of robotics applications on the custom UniBase platform. It abstracts low-level hardware control (motors, encoders, OLED display, sensors) into an intuitive, high-level C++ API.

Whether you are a student learning robotics or a maker building complex autonomous behaviors, UNI provides the tools to get your robot moving in minutes.
