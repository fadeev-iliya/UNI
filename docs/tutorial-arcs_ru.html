Дуги

Поворот на месте — это остановка. Дуга меняет направление на ходу: скругляет углы и ведёт робота по плавной траектории.

Два способа задать дугу

Через соотношение скоростей колёс. Так работают moveArcDist(), moveArcTime() и motorsArc(). Параметр angle от −90 до 90 задаёт крутизну: левое колесо получает power × (1 + angle / 90), правое — power × (1 − angle / 90).

angle Левое колесо Правое колесо Что делает робот
0× 1× 1Едет прямо
30× 1,33× 0,67Плавная дуга вправо
45× 1,5× 0,5Крутая дуга вправо
90× 20Разворот вокруг правого колеса
-30× 0,67× 1,33Плавная дуга влево

Через геометрию. moveArcRadius() принимает радиус дуги по центру робота и угол сектора.

Оба способа описывают одно и то же: angle = 90 × (колея / 2) / радиус. При стандартной колее 107 мм angle = 30 соответствует радиусу около 160 мм.

Шаги

  1. Скруглите углы квадрата

    for (int i = 0; i < 4; i++) {
  robot.moveDist(50, 250);
  robot.moveArcRadius(50, 100, 90);   // четверть круга радиусом 100 мм
}

    Вместо разворота на месте робот проходит угол по четверти окружности.

  2. Проедьте змейкой

    for (int i = 0; i < 3; i++) {
  robot.moveArcDist(50, 30, 250);    // дуга вправо
  robot.moveArcDist(50, -30, 250);   // дуга влево
}

    Третье число — длина дуги по центру робота в миллиметрах. При angle = 30 дуга длиной 250 мм — это примерно четверть окружности.

  3. Ведите дугу вручную

    robot.motorsArc(40, 20);   // едет по дуге, пока его не остановят
delay(2000);
robot.stop(SOFT);

    motorsArc() не имеет цели: робот едет по дуге до вызова stop(). SOFT останавливает без блокировки колёс, HARD — тормозом.

Попробуйте изменить

  • Сравните радиусы 60, 150 и 300 мм в moveArcRadius().
  • Проедьте полный круг: robot.moveArcRadius(50, 150, 360), а затем такой же влево с углом -360 — получится восьмёрка.
  • Задайте angle больше 90 в moveArcDist() и посмотрите, что делает внутреннее колесо.

Если не получается

  • moveArcRadius() ничего не делает. Радиус должен быть не меньше половины колеи — 53 мм, а угол не равен нулю. Для разворота на месте используйте rotate().
  • Дуга получается не той кривизны. Кривизна зависит от колеи: проверьте, что колёса не проскальзывают, — см. FAQ.
